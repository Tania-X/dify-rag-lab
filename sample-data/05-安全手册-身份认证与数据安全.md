# 安全手册 · 身份认证与数据安全（示例文档）

> 演示语料：虚构公司"星云科技"研发中台知识库。内容贴近真实工程实践，用于 Dify 向量化演练。

## 1. 身份认证

- 认证方式：统一走 SSO（OIDC），禁止各系统自建账号体系；内部系统必须支持企业微信扫码登录。
- Access Token：JWT，有效期 15 分钟；Refresh Token：有效期 7 天，可撤销（Redis 黑名单）。
- Token 存储：前端放内存 + 刷新接口，禁止存 localStorage（XSS 风险）。
- 双因子：管理员、财务、运维角色强制开启 MFA（TOTP）。
- 会话审计：登录/登出/改密/踢人事件全量记录，异常登录（异地/新设备）触发风控提醒。

## 2. 密钥管理

- 密钥分级：A 类（云厂商 AK/SK、数据库密码、签名私钥）→ 密钥管理系统（KMS），B 类（第三方 API Key）→ 配置中心加密存储。
- 禁止：密钥写进代码库、配置文件、日志、镜像层；扫描工具（gitleaks）进 CI 门禁。
- 轮换：A 类密钥 90 天强制轮换，B 类 180 天；轮换必须支持双密钥平滑过渡（新旧并行 24h）。
- 分发：密钥不通过 IM/邮件传输，统一走 KMS 授权读取，操作留痕。

## 3. 数据分级与脱敏

- 分级：L1 公开 / L2 内部 / L3 敏感（手机号、身份证、地址）/ L4 机密（财务、密钥、原始日志）。
- 脱敏规则：手机号 `138****5678`，身份证保留前 3 后 4，银行卡保留后 4 位；日志/导出/前端展示统一走脱敏过滤器。
- 存储加密：L3 及以上字段必须加密存储（AES-256-GCM，密钥在 KMS）；传输一律 TLS 1.2+。
- 数据导出：L3+ 数据导出必须审批（DLP 拦截 + 水印 + 审计），导出文件 7 天自动过期。
- 数据保留：日志 180 天、订单 7 年、个人敏感数据按"最小必要"原则定期清理（GDPR/个保法）。

## 4. 接口安全

- 认证：对外接口必须带 Token；内部服务间用 mTLS 或私有网络 + 服务身份（禁止裸 IP 互调）。
- 防注入：所有 SQL 必须参数化；禁止拼接；前端输入一律校验 + 转义。
- 防越权：水平越权（改他人数据）必须做资源级鉴权（owner 校验），上线前必须过越权测试用例。
- 频控：登录/验证码接口按 IP+账号双重限流（5 次/分钟），防暴力破解。
- 文件上传：白名单扩展名 + 内容嗅探 + 病毒扫描；上传目录禁止执行权限。

## 5. 安全运营

- 漏洞治理：高危漏洞 24 小时内修复并复盘，中危 7 天；依赖扫描（Snyk/OWASP DC）进 CI。
- 渗透测试：核心系统每半年 1 次外部渗透，问题闭环率 100%。
- 应急响应：安全事件 10 分钟内响应，30 分钟内初步定性（蓝队值班表 7×24）。
- 合规：个保法影响评估（PIA）、等保 2.0 三级每年度检；供应商安全评估（SSF）每年 1 次。
