# 研发规范 · 接口设计与 API 网关（示例文档）

> 演示语料：虚构公司"星云科技"研发中台知识库。内容贴近真实工程实践，用于 Dify 向量化演练。

## 1. REST 设计规范

- 资源命名：名词复数（`/orders`、`/users/{id}/addresses`）；禁止动词（用 `POST /orders/{id}/cancel` 这类动作子资源时须评审）。
- 动词语义：GET 查询（无副作用）、POST 创建/触发动作、PUT 全量替换、PATCH 局部更新、DELETE 删除。
- 版本：URL 前缀 `/v1`，破坏性变更升 `/v2`；同一接口兼容期 ≥ 6 个月。
- 响应：统一信封 `{code, message, data, trace_id}`；分页返回 `{items, page, page_size, total}`。
- 时间：统一 ISO8601 UTC（`2026-08-27T10:00:00Z`）；金额统一为分（long），前端自行换算。

## 2. 错误码规范

- 三段式：`[服务域][模块][序号]`，如 `A1001`（账户域-登录模块-01）。
- 公共码：`0` 成功；`10001` 参数错误；`10002` 未认证；`10003` 无权限；`10004` 资源不存在；`10005` 频控；`10006` 服务不可用。
- 错误响应必须带 `message`（面向调用方）与 `detail`（面向排障，脱敏），禁止返回堆栈。
- 错误码字典：统一在 API 网关注册，Swagger/OpenAPI 中标注每个接口的完整错误码集合。

## 3. 幂等与限流

- 幂等：所有"创建/支付/通知"类接口必须支持 `Idempotency-Key`（请求头，UUID），服务端按 Key 去重 24 小时。
- 限流：网关层按 `API + 租户 + 用户` 三维限流；默认单用户 100 QPS，超限返回 `10005` + `Retry-After`。
- 熔断：下游依赖错误率 > 30% 触发熔断（半开探测 30s）；超时统一 3s，禁止无限等待。
- 重试：幂等接口可自动重试 ≤ 2 次（指数退避）；非幂等接口只允许业务层显式重试。

## 4. API 网关（星云网关）

- 功能：认证鉴权（JWT/OAuth2 透传）、路由、限流、熔断、灰度（按 header/百分比）、审计日志。
- 灰度：`X-Gray-Tag` header 或按 user_id 哈希 10%；灰度流量染色进全链路 trace。
- 审计：所有写操作记录 `who/what/when/ip/trace_id`，保留 180 天，支持导出。
- 网关变更：路由/限流配置走 GitOps（PR 审批后自动生效），禁止线上手改。

## 5. 契约管理

- OpenAPI 3.0：所有对外接口必须有 `openapi.yaml`，由代码生成（springdoc）并提交到契约仓库。
- 契约评审：新增/变更接口必须过接口评审（每周二 14:00），重点看兼容性与错误码。
- Mock：契约仓库自动生成 mock server，前端与下游联调一律先打 mock。
- 兼容性：新增可选字段允许；删除/重命名字段必须走新版本；字段类型变更视为破坏性。
