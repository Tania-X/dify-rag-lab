# 星云金融科技 · 数据质量管理规范

## 1. 质量维度

- 完整性：关键字段不允许为空。
- 准确性：数据必须与业务事实一致。
- 及时性：核心交易数据延迟不超过 1 分钟。
- 一致性：跨系统同一指标口径一致。

## 2. 质量规则

- 订单金额必须大于 0。
- 订单状态必须属于合法枚举值。
- 身份证号必须通过校验规则。
- 手机号必须为 11 位数字。

## 3. 问题处理

- P0 数据质量问题：1 小时内响应，4 小时内修复。
- P1 数据质量问题：4 小时内响应，24 小时内修复。
- P2 数据质量问题：24 小时内响应，3 个工作日内修复。

## 4. 考核

- 每月统计数据质量得分。
- 目标得分不低于 99.5%。
- 连续两个月低于 99% 的，启动专项整改。
