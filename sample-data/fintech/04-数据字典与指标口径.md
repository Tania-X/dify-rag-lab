# 星云金融科技 · 数据字典与指标口径

## 1. 订单状态

| 状态码 | 含义 | 说明 |
|---|---|---|
| 0 | 待支付 | 订单已创建，等待用户支付 |
| 1 | 支付中 | 已发起支付，等待渠道结果 |
| 2 | 支付成功 | 渠道已确认收款 |
| 3 | 支付失败 | 渠道返回失败或超时 |
| 4 | 已关闭 | 超时未支付自动关闭 |
| 5 | 已退款 | 订单完成退款 |

- 订单创建后 30 分钟未支付自动关单，定时任务每分钟扫描一次。
- 已关闭订单不允许再次支付，需重新下单。

## 2. 支付状态

- 支付状态与订单状态分离维护。
- 支付单状态：INIT、PROCESSING、SUCCESS、FAILED、CLOSED、REFUNDED。
- 渠道回调与本地状态不一致时，以对账结果为准。

## 3. 对账指标

- 支付成功率 = 支付成功笔数 / 支付发起笔数。
- 支付差错率 = 对账差异笔数 / 总交易笔数。
- 对账完成率 = 已核对笔数 / 应核对笔数。
- 日终对账必须在次日 02:00 前完成。

## 4. 风控指标

- 可疑交易率 = 触发可疑交易笔数 / 总交易笔数。
- 人工复核通过率 = 确认可疑笔数 / 人工复核笔数。
- 上报及时率 = 24 小时内上报笔数 / 应上报笔数。

## 5. 数据质量要求

- 核心交易表数据延迟不超过 1 分钟。
- 报表数据延迟不超过 15 分钟。
- 数据字典变更必须同步更新元数据系统，并通知下游消费方。
