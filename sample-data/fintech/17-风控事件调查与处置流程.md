# 星云金融科技 · 风控事件调查与处置流程

## 1. 事件分级

- P0：盗刷、资金被盗、系统性攻击。
- P1：疑似欺诈、批量异常交易。
- P2：一般异常交易。
- P3：低风险提示。

## 2. 调查时限

- P0 事件 30 分钟内启动调查。
- P1 事件 2 小时内启动调查。
- P2 事件 4 小时内处理。
- P3 事件 24 小时内处理。

## 3. 处置措施

- 冻结账户。
- 拦截交易。
- 撤回渠道请求。
- 上报合规/反洗钱。
- 通知客户。

## 4. 结案要求

- 每起事件必须输出调查报告。
- 报告包含事件经过、影响范围、处置动作、改进建议。
- 报告归档保存至少 3 年。
