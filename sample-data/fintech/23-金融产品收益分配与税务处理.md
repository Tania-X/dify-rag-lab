# 星云金融科技 · 金融产品收益分配与税务处理

## 1. 收益分配

- 基金分红方式分为现金分红和红利再投资，默认现金分红。
- 理财产品收益按实际天数计算，年化收益率仅供参考。
- 分红方案需提前 3 个工作日公告。

## 2. 税务处理

- 个人购买公募基金分红暂不征收个人所得税。
- 企业购买理财产品取得的利息收入需缴纳增值税。
- 代扣代缴义务由产品发行方承担。

## 3. 信息披露

- 收益分配后 2 个工作日内向客户发送对账单。
- 对账单需列明本金、收益、费用、净值。

## 4. 争议处理

- 收益计算争议需在 5 个工作日内核实并答复。
- 属于系统错误的，按差额补付并追责。
